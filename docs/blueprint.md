# **App Name**: Client Keeper

## Core Features:

- User Authentication: Allows users to register and login using OTP authentication via email or phone number.
- Customer List: Displays a sortable and searchable list of customers. Customers can be sorted by birthday, date added, full name, and phone number. Data stored in Firestore.
- Add Customer: Presents a form to add new customers, including fields for name, phone number, birthday, and tags, with an option to import from contacts. Data stored in Firestore.

## Style Guidelines:

- Primary color: A calming blue (#3498db) for a professional feel.
- Secondary color: A clean white (#ffffff) for backgrounds and content areas.
- Accent: A vibrant green (#2ecc71) for success messages, primary buttons, and highlights.
- Employ a bottom navigation bar for main sections: Customers, Add Customer, Export/Import, Settings.
- Use clear and consistent Material Design icons throughout the app.
